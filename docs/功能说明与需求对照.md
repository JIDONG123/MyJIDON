# 功能说明与官方需求对照

本文档描述系统能力与竞赛/官方需求的**逐项对照**，不涉及服务器部署操作（部署见 [部署指南-麒麟LoongArch.md](./部署指南-麒麟LoongArch.md)）。

---

## 一、官方需求对照（审核结论）

| 需求项 | 实现状态 | 说明 |
|--------|----------|------|
| **1. 大模型服务接入** | **已实现** | 管理端「系统设置」可配置 `API Base`、`API Key`、`模型名`；后端 `llmClient` 以 OpenAI 兼容协议调用 `/v1/chat/completions`；支持「测试大模型连接」校验云端可用性。 |
| **Web 可视化配置** | **已实现** | `SystemSettings.vue`（管理员） |
| **2. 实训成果上传与解析** | **已实现** | 支持 docx、pdf、图片、txt/md、zip 等（见 `backend/middleware/upload.js`、`backend/services/fileParser.js`）；后端抽取文本写入 `submissions.content` 供批改。 |
| **3. 智能核查** | **已实现** | `backend/utils/aiGrading.js` 要求 LLM 输出 `verification`（要求对比、逻辑问题、步骤完整性、摘要）；未配置 API 时使用内置演示规则，便于离线演示。 |
| **4. 多维度评价与权重** | **已实现** | 任务表 `evaluation_metrics`（JSON：名称/权重/满分）；AI 按维度评分；教师复核 `humanReview` + 系统权重 `score_ai_weight` / `score_human_weight` 计算综合分。 |
| **5. 报表导出** | **已实现** | 个人评价 PDF：`/api/reports/submission/:id/pdf`；班级统计：教师/管理员「成绩统计」柱状图、饼图、雷达图；Excel：`/api/dashboard/class/:id/export`（「成绩明细」+「统计摘要」）；班级 PDF：`/api/reports/class/:id/pdf`（明细列表；复杂图表以 Web 为准）。 |
| **角色权限** | **已实现** | JWT + `requireRole`；路由守卫按 `matched` 链校验 `meta.role`；管理员 / 教师 / 学生菜单分离。 |
| **前后端分离** | **已实现** | Vue3 + Vite / Express API |
| **登录鉴权** | **已实现** | `Bearer` Token，Axios 拦截器附带头 |

---

## 二、三角色能力概要

| 角色 | 主要功能入口 |
|------|----------------|
| **管理员** | 用户管理、班级管理、实训任务管理、系统设置（大模型与权重）、**报表统计**（与教师同源页面）、批改详情 |
| **教师** | 发布/编辑任务、查看提交、AI 批改、批改详情与复核、成绩统计与导出 |
| **学生** | 查看任务、上传成果、我的提交、成绩查询与个人报告 |

---

## 三、技术栈与目录

| 部分 | 说明 |
|------|------|
| 前端 | `frontend/`：Vue 3、Vite、Element Plus、ECharts、Pinia |
| 后端 | `backend/`：Express、MySQL、`mysql2`、JWT、Multer、PDF/Office 解析 |
| 数据库脚本 | `backend/sql/init.sql` 及 `migration_*.sql` |

## 四、近期能力补充（验收备忘）

- **大模型连接测试**：管理员在「系统设置」保存配置后，可使用「测试大模型连接」。  
- **班级 Excel**：「成绩明细」+「统计摘要」（记录数、均分、最高/最低分）；导出目录 `backend/exports`。  
- **管理员报表统计**：侧栏「报表统计」，与教师端共用班级统计与图表。  
- **全局 UI**：`frontend/src/styles/theme.css` 统一主色；登录页分栏布局；三端 Layout 主内容区滚动与内边距；路由切换过渡动画。
