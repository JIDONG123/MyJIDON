# 7 分钟演示脚本

> **龙芯智训 · 校企实训智慧评价平台**  
> 面向：高校软件实训、校企协同、项目制教学、国产化（LoongArch / 麒麟）答辩

建议分辨率 1920×1080，浏览器全屏；提前启动 backend + BullMQ worker + Nginx。

## 账号（示例，以 seed 为准）

| 角色 | 账号 | 说明 |
|------|------|------|
| 管理员 | admin | 基础数据与监管 |
| 教师 | teacher1 | 发布任务、批改、学情 |
| 学生 | student1 | 提交、报告、AI 助手 |
| 企业 | test-enterprise-01 | 企业评价（可选） |

## 时间线（约 7 分钟）

### 0:00–0:45 管理端 · 基础与监管

1. 管理员登录 → 仪表盘
2. 快速展示：专业/学期/课程/教学班结构
3. **内容安全复核** 或 **系统设置**（LLM、Neo4j 开关）— 体现平台可配置

**话术要点**：统一底座、多角色、国产化可部署。

### 0:45–1:30 教师 · 发布实训

1. 教师登录 → 任务列表 → 打开「Java 基础练习题」类任务
2. 展示：评分维度、代码运行检查、RAG 知识库关联
3. 教学班任务已发布给学生（不必现场新建，避免超时）

**话术要点**：项目制实训、评价标准结构化。

### 1:30–2:30 学生 · 多模态提交

1. 学生登录 → 实训中心 → 进入任务
2. 展示：文字说明、代码区、**多附件**上传
3. 可选：代码运行检查通过后再提交
4. 提交成功 → 提交历史/版本（若有）

**话术要点**：全过程留痕、代码+文档+附件一体化。

### 2:30–3:30 AI 异步批改

1. 切换教师 → 提交列表 → **单份 AI 批改** 或查看进行中 job
2. 打开 **批改任务列表** / 进度面板 — BullMQ 异步
3. 完成后打开批改结果：维度分、AI 评语、核查项

**话术要点**：LangChain 多步 + 队列削峰，教师可复核。

### 3:30–4:15 教师复核与企业评价

1. 人工复核 / 修正分数（可选 1 条）
2. 企业导师登录 → 查看授权提交 → 企业维度评价（若启用）

**话术要点**：校企协同、双轨评价。

### 4:15–5:00 学生 · 报告与反馈

1. 学生 → 成绩报告 / 结果详情（PDF 或页面报告）
2. **作业反馈 / 申请重交**（若演示数据有退回场景）

**话术要点**：评价闭环、改进重交。

### 5:00–5:45 学情与知识图谱

1. 教师 → 学情统计 / 弱项分析
2. **知识图谱**：班级掌握 / 课程任务视图切换

**话术要点**：数据驱动教学、Neo4j 图谱（可选模块）。

### 5:45–6:30 学生 AI 助手（SSE 流式）

1. 学生 → AI 助手 → 提问（如「解释 Spring MVC 请求流程」）
2. 强调：**逐字/逐段流式输出**、引用知识库 sources
3. 停止生成、Markdown 格式与代码块可读

**话术要点**：RAG + SSE，Nginx 生产级流式配置。

### 6:30–7:00 架构与国产化亮点

1. 切换 PPT 或文档 [02-architecture.md](./02-architecture.md)
2. 一句话栈：Vue3 + Node + MariaDB + Redis + BullMQ + Neo4j + Nginx
3. 龙芯 VM systemd 部署、Docker 云 ECS 双路径

**话术要点**：LoongArch 适配、可评审、可维护工程化文档。

## 演示前清理建议

- 勿在演示前运行 `regression:grading:live` 或 `seed:test` 污染数据
- 关闭失败/卡住的 grading job 或改用已完成样本
- 确认 Worker 运行中，避免「批改一直排队」

## 备用预案

| 风险 | 应对 |
|------|------|
| LLM 超时 | 使用已批改完成的提交展示结果页 |
| SSE 不流式 | 直连后端 `:8080` 对比 Nginx；检查 assistant location |
| Worker 未启 | `systemctl status smart-grading-grading-worker` |
