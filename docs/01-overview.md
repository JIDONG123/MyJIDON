# 01 — 项目概述与功能清单

## 1.1 项目定位

**智能实训作业批改管理系统**（龙芯智训 / B1 LoongArch Grading System）面向高职「高校—企业协同实训」场景，覆盖实训任务发布、多格式成果上传与解析、大模型/LangChain 智能批改、教师与企业双重复核、知识库 RAG、Neo4j 知识图谱、题库练习与在线考试、学情分析与报表导出等完整教学闭环。

- **前端**：Vue 3 SPA，四角色独立工作台（管理员 / 教师 / 学生 / 企业导师）
- **后端**：Node.js + Express 集群，REST API + Socket.IO 实时通道
- **部署**：龙芯 VM 宿主机 + Neo4j Docker；或云 ECS Docker Compose 全栈

## 1.9 身份认证与账户管理（增强说明）

### 登录与安全

| 能力 | 实现 |
|------|------|
| 图形验证码 | 后端 `captchaService.js` 生成 SVG，Redis 缓存 5 分钟；登录接口校验 `captchaId` + `captchaCode` |
| 忘记密码 | 校验用户名与绑定邮箱一致；Redis 限流（同账号 2 分钟 1 次）；nodemailer 发 HTML 邮件 |
| 重置链接 | `{PUBLIC_APP_URL}/reset-password?token=...`；令牌 Redis 15 分钟；成功后同步更新 `password` 与 `password_plain` |
| 登录态 | 前端 `sessionStorage` 存 Token/用户信息；关闭浏览器标签或窗口后需重新登录 |
| JWT | 默认 `JWT_EXPIRES_IN=8h`；可在 `.env` 调整 |

### 账号密码管理

| 角色 | 能力 | API |
|------|------|-----|
| 管理员 | 学生/教师列表查看明文密码 | 列表接口返回 `password_plain`；`GET /api/users/:id/password` |
| 管理员 | 修改任意用户用户名/密码 | `PUT /api/users/:id` |
| 教师 / 学生 | 自主修改用户名/密码 | `PATCH /api/users/me/credentials`（需当前密码） |
| 数据库 | 明文备份字段 | `users.password_plain`（迁移 `migration_password_plain.sql`） |

> **安全提示**：`password_plain` 便于校内实训账号分发，生产环境应限制管理员权限并修改默认密码。

### M06 批改流水线

| 模式 | 触发条件 | 步骤 |
|------|----------|------|
| 单步 LLM | `USE_LANGCHAIN_GRADING≠1` 或链失败降级 | 一次 LLM 调用输出分数 + verification |
| LangChain 四步 | `USE_LANGCHAIN_GRADING=1` | ① 内容解析 → ② 任务+RAG 对齐 → ③ 多维评分 → ④ 总结反馈 |
| 异步 job | 教师/管理员触发 AI 批改 | HTTP 入队 → Redis List → **独立 Worker** 逐条 `runSingleGrading` |
| 批量批改 | 教师触发 | 同上；`legacy_batch_id` 兼容旧 `batch-progress` 轮询 |
| 综合分 | 始终 | `score_ai × W_ai + score_human × W_human (+ 企业分)` |

**前端体验：** 点击 AI 批改后立即提示「任务已进入后台」；右下角进度卡片 + **批改任务**页；不再全屏遮罩等待 LLM。

**教师批改页（2025-05 UI）：** `/teacher/grading/:submissionId` 首屏即展示智能核查结果与教师修正区；学生全文/OCR/深度分析默认折叠在下方。批改列表对「已提交未批改」统一显示 **待批改**。详见 [09-frontend-teacher-ui.md](./09-frontend-teacher-ui.md)。

**去重：** 同一 submission 若已有 `pending/running` 的 job item，返回已有 `jobId`，不重复入队。

**输出兼容：** `aiGrading.js` / `langchainGradingService.js` / `gradingFinal.js` 的 JSON 结构未改；`grading_results` 表字段不变。
